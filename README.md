# Jong Abawag — Portfolio (v2)

Portfolio of a Business Applications Developer — the marketing-page revamp of
[jongabawag.github.io/myportfolio](https://jongabawag.github.io/myportfolio/) (v1, still live).

Plain HTML/CSS/JS + GSAP via CDN. No build step.

**Live (once GitHub Pages is enabled for this repo):** https://jongabawag.github.io/

## Local preview

```bash
python -m http.server 8208
# open http://127.0.0.1:8208/index.html
```

## What's in the v2 revamp

- Giant hero value statement ("I build apps that run real businesses.") — name as byline
- Floating app-window proof band with cursor parallax + idle drift
- Live simulated checkout feed (labeled as simulated) inside the proof band
- Pinned scroll process (01→04 scrollytelling, desktop only)
- Full-width honesty marquees (true facts only)
- Receipt-style stat band (verifiable 8/4/1/3, counts shipped work only)
- Oversized rotating pull quotes with REF-code pager
- 3D tilt on project cards
- Scroll progress bar with "% read" readout
- "Let's build yours." sign-off above the footer

Design reference mockups live in `_design/`.
